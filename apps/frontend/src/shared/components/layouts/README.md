# shared/components/layouts

Estructura de una pantalla (shell, loading, error, columna de página). Pueden importar de todos los niveles.

- **Archivos:** `<nombre>.tsx` en kebab-case.
- **Qué NO va:** lógica de negocio, llamadas a adapters o services, componentes específicos de una sola feature (van en `features/<feature>/views/`).
